# OSINT SaaS – TRACE-X

## 🚀 Problem
Digital identity exposure across platforms is fragmented, invisible, and unmanaged.

## 💡 Solution
TRACE-X is an autonomous OSINT SaaS that:
- Scans usernames across platforms
- Tracks exposure over time
- Detects deltas (new / removed signals)
- Assigns platform-level risk
- Flags reverse-OSINT threats

## 🧠 Core Features
- Autonomous OSINT scan engine
- Exposure timeline & delta detection
- Risk scoring engine
- Reverse OSINT signal detection
- Web dashboard (FastAPI + React)

## 🏗️ Tech Stack
- Backend: FastAPI, SQLAlchemy, SQLite
- Frontend: React, TypeScript, Vite
- OSINT Logic: Custom rule engines
